# Security Module

Combined security operations module for visitor/security validation, goods in/out permits, work permits, work-permit files, and access-card requests. See `Docs/Architecture/SECURITY_STRUCTURE.md`.


## Cleaners-First Product Focus

The module is now oriented around a simpler cleaning-operations MVP:

- cleaner registration and approval
- cleaner access-card linkage
- site check-in/check-out logs
- work permits linked to cleaners
- goods/equipment in-out linked to cleaners
- supervisor approval and basic reporting

Enterprise blueprint folders are retained for future expansion, but the active product path is intentionally smaller and operational.
