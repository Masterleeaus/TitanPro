# Accountings Single Control Panel

This module follows the Titan AI Controlled Module Blueprint. All operator UI is surfaced through one Filament control panel page, backed by the module UI manifest and AI control manifest.

- UI manifest: `UI/manifests/ui.json`
- AI control manifest: `AI/Control/control.manifest.json`
- Filament page: `Filament/Pages/*ControlPanel.php`
- Blade shell: `Resources/views/filament/pages/control-panel.blade.php`
- Anonymous components: `Resources/views/components/ui/*.blade.php`
