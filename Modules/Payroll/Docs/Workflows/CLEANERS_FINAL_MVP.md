# Cleaners Payroll MVP Final Layer

This pass adds the final practical surface for a cleaning-business launch:

- cleaner payroll dashboard widgets
- configurable shift loading / allowance settings
- employee self-service payslip listing
- bank detail update request endpoint
- tax declaration status endpoint
- Filament resource metadata for cleaner payroll runs

Recommended launch scope:

1. Configure loadings and allowances per company.
2. Preview cleaner shift payroll before posting salary slips.
3. Approve the payroll run.
4. Generate payslips.
5. Deliver payslips automatically.
6. Lock the payroll period.

Deferred until after launch:

- advanced multi-country tax packs
- workflow designer UI
- full ERP marketplace integrations
- heavy AI forecasting agents
