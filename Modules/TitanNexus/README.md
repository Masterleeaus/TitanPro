# Titan Nexus

Titan Nexus is an AI-native lead generation, marketing orchestration, payment follow-up and job-assist module.

## Core capabilities
- Lead discovery, enrichment, scoring and campaign automation
- MarketingAgent with tools, prompts, memory, retrieval, guardrails and telemetry
- Late invoice follow-up drafts and payment-assist workflows
- Job status assistant for Ground Zero handoff/customer updates
- Single module control panel with tables, widgets, cards and agent console
- Event-driven automations, workflows, jobs, listeners, mail and notifications

## Safety model
External outreach, payment nudges, payment plans, and booking/job handoffs are staged behind approval gates unless tenant policy explicitly enables automation.
