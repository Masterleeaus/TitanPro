# Agent Integration Kit (v3) — AICopilot + Worksuite
**Date:** 2025-11-01

This kit equips contractors to integrate or extend modules against **AICopilot** using BOTH:
- **Local Facade (no HTTP):** fastest in-process calls
- **HTTP API:** stable public interface (module boundary, future-proof)

It follows Worksuite/NWidart conventions: Providers, Routes, Sidebar, Migrations, Plan/Permission gating, and Widgets.
